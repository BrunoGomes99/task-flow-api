# Browser CORS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow a browser on a configured origin to call the API with a Bearer token, starting with `http://localhost:4200` in Development.

**Architecture:** The API project owns a `Cors` settings section and one named CORS policy, `TaskFlow`. `UseCors` runs before authentication so preflight does not need a JWT. Production origins come from the ECS API task environment, fed by Terraform `cors_allowed_origins`, which defaults to an empty list.

**Tech Stack:** ASP.NET Core 10 CORS middleware, xUnit, Terraform variable on the existing API task definition.

**Spec:** [../specs/2026-11-10-cors-design.md](../specs/2026-11-10-cors-design.md)

## Global Constraints

- Policy name is `TaskFlow`.
- Section name is `Cors`. The only setting is `AllowedOrigins`.
- Base `appsettings.json` list is empty. Development list is `http://localhost:4200` only.
- Never call `AllowAnyOrigin`. `SupportsCredentials` stays false.
- Methods: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
- Headers: `Authorization`, `Content-Type`, `Accept`.
- `UseCors` is after `UseHttpsRedirection` and before `UseAuthentication`.
- Empty origins are valid and allow no cross-origin browser call.
- Trim whitespace and a single trailing slash in the app. Do not accept a path or query in Terraform.
- `cors_allowed_origins` defaults to `[]` and is set only on the API container as `Cors__AllowedOrigins__N`.
- Do not add the variable to the scheduler or notifications tasks.
- Do not change controllers, JWT, refresh tokens, or the ALB listeners.
- Do not hardcode a Cloudflare Pages hostname.
- Tests build the policy from `ICorsPolicyProvider`. They do not boot `Program` and they do not need MongoDB.

    {
        var policy = await BuildPolicyAsync(new Dictionary<string, string?>

            ["Cors:AllowedOrigins:1"] = " ",
            ["Cors:AllowedOrigins:2"] = "http://localhost:4200"

        Assert.Equal("http://localhost:4200", Assert.Single(policy.Origins));
    }

    public async Task Policy_WithNoOrigins_AllowsNone_AndDoesNotThrow()
    {
        var policy = await BuildPolicyAsync(new Dictionary<string, string?>());

        Assert.Empty(policy.Origins);
        Assert.False(policy.AllowAnyOrigin);
        Assert.False(policy.SupportsCredentials);
    }

    private static async Task<CorsPolicy> BuildPolicyAsync(Dictionary<string, string?> values)

        services.AddTaskFlowCors(configuration);
        await using var provider = services.BuildServiceProvider();
        var policy = await provider.GetRequiredService<ICorsPolicyProvider>()

        Assert.NotNull(policy);
        return policy;
    }

`src/TaskFlow.Api/Extensions/CorsExtensions.cs`:

```csharp
using Microsoft.AspNetCore.Cors.Infrastructure;
using Microsoft.AspNetCore.Http;
using Microsoft.Net.Http.Headers;
using TaskFlow.Api.Configuration;

namespace TaskFlow.Api.Extensions;

public static class CorsExtensions
{
    public const string PolicyName = "TaskFlow";

    public static IServiceCollection AddTaskFlowCors(this IServiceCollection services, IConfiguration configuration)
    {
        ArgumentNullException.ThrowIfNull(services);
        ArgumentNullException.ThrowIfNull(configuration);

        var settings = configuration.GetSection(CorsSettings.SectionName).Get<CorsSettings>();
        var origins = Normalize(settings?.AllowedOrigins ?? []);

        services.AddCors(options =>
        {
            options.AddPolicy(PolicyName, policy =>
            {
                if (origins.Length > 0)
                    policy.WithOrigins(origins);

                policy.WithMethods(
                        HttpMethods.Get,
                        HttpMethods.Post,
                        HttpMethods.Put,
                        HttpMethods.Patch,
                        HttpMethods.Delete)
                    .WithHeaders(HeaderNames.Authorization, HeaderNames.ContentType, HeaderNames.Accept)
                    .DisallowCredentials();
            });
        });

        return services;
    }

    private static string[] Normalize(IEnumerable<string> origins)
    {
        return origins
            .Select(origin => origin.Trim().TrimEnd('/'))
            .Where(origin => origin.Length > 0)
            .Distinct(StringComparer.Ordinal)
            .ToArray();
    }
}
```

- [x] **Step 1: Add the root variable**

In `infra/variables.tf`:

```hcl
variable "cors_allowed_origins" {
  description = "Browser origins allowed to call the API. Empty allows no cross-origin browser call. Set the Cloudflare Pages origin when that hostname exists."
  type        = list(string)
  default     = []

  validation {
    condition = alltrue([
      for origin in var.cors_allowed_origins :
      can(regex("^https?://[A-Za-z0-9.-]+(:[0-9]+)?$", origin))
    ])
    error_message = "Each CORS origin must be an absolute http or https origin with no path, query, or trailing slash."
  }
}
```
